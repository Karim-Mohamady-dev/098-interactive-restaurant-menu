# قائمة المطعم التفاعلية

قائمة طعام ثنائية اللغة مع بحث وتصنيفات وتصفية نباتي ونباتي صرف وخال من الجلوتين وحار، وقائمة طلب مع كميات وإجمالي وملاحظة للمطبخ وتأكيد طلب برقم. الصور مرسومة بـ CSS وأيقونات، ولا توجد صور خارجية. الأسعار أسعار عينة بالجنيه المصري.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## اللغات

عربي (RTL) وإنجليزي (LTR) مع مبدّل لغة ظاهر، والتفضيل محفوظ في localStorage. ملفات الترجمة في `locales/en/common.json` و`locales/ar/common.json`.

## التقنية

React + TypeScript + Vite + Tailwind CSS. أيقونات Phosphor.
